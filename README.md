# Reporting Automation — Download

App desktop **Reporting Automation** (beban training Induction & Basic 1).
Halaman ini hanya berisi file installer; kode dan data tidak ada di sini.

## Download versi terbaru

Buka **[Releases → Latest](../../releases/latest)**, lalu pilih:

| Laptop | File |
|---|---|
| **Windows** | `Reporting-Automation-<versi>-win-x64.exe` |
| **Mac Apple Silicon (M1/M2/M3/M4)** | `Reporting-Automation-<versi>-mac-arm64.dmg` |
| **Mac Intel** | `Reporting-Automation-<versi>-mac-x64.dmg` |

## Pasang

- **Windows:** jalankan file `.exe`. Bila muncul *Windows protected your PC*, klik **More info → Run anyway**.
- **Mac:** buka `.dmg`, seret app ke **Applications**. Pertama kali buka: klik kanan app → **Open**
  (atau System Settings → Privacy & Security → **Open Anyway**).

## Update

App memeriksa versi terbaru setiap dibuka. Bila ada versi baru, app meminta update dulu:
- Windows: klik **Update sekarang**, installer baru otomatis diunduh dan dijalankan.
- Mac: klik **Update sekarang**, halaman download terbuka; pasang DMG baru seperti di atas.
